# Image credits

## Current state

No licensed photography has been sourced yet. Every image slot currently renders
the `<SmartImage>` placeholder, which is generated in code (gradient + geometric
pattern + label). No third-party assets are in use.

## Planned sources

When photography is added, prefer, in order:

1. Client-supplied photography (JCNL owns it; no attribution required beyond a
   note that it was supplied by the client).
2. Unsplash or Pexels, under their licences (no attribution required, but the
   photographer is credited here as good practice).
3. Wikimedia Commons, under the licence stated on the file page (attribution and
   share-alike terms must be reproduced here).

Record each asset as:

```
<file> — <subject>
Source: <URL>
Photographer: <name>
Licence: <name + URL>
Modifications: <crop, colour grade, etc.>
```
